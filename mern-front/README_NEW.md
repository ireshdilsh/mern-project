# AI-Powered Family Memory Keeper 📸✨

A modern web application built with React + TypeScript + Vite that helps families preserve, organize, and relive their precious memories using AI technology.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 🌟 Features

- **AI-Powered Organization** - Automatically categorize photos and videos
- **Smart Albums** - AI creates albums based on events and people
- **Video Stories** - Generate cinematic highlight reels automatically  
- **Family Sharing** - Collaborate with family members securely
- **Image Enhancement** - AI-powered photo restoration
- **Timeline View** - Browse memories chronologically

## 📦 Tech Stack

- React 19 + TypeScript
- Vite for fast development
- TailwindCSS 4 for styling
- React Router for navigation
- Axios for API calls

## 🎨 Pages

- `/` - Landing page with hero and features
- `/login` - User authentication
- `/register` - User signup
- `/dashboard` - Main dashboard with stats and timeline
- `/upload` - Upload media with AI processing options
- `/albums` - Manage and view photo albums
- `/stories` - AI-generated video stories
- `/family-groups` - Family member management

## ⚠️ Important Note

This is a **UI-only implementation** created for design demonstration purposes. **No backend functionality is integrated.** All features shown use mock data and are meant to showcase the user interface design.
